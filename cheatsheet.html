Dev keys cheatsheet

⌥ AeroSpace ⌃Space tmux prefix Space nvim leader

AeroSpace Windows

Everything uses ⌥ Option.

⌥hjklFocus window left / down / up / right
⌥⇧hjklMove window
⌥fFullscreen toggle
⌥⇧fFloat ↔ tile this window
⌥/Tiles layout (press again: flip horizontal/vertical)
⌥,Accordion layout
⌥- / ⌥^Shrink / grow (JIS ^ = US =)
⌥↩New iTerm window

AeroSpace Workspaces

Apps open on their own workspace. All workspaces live on the external monitor; undocked they fall back to the laptop.

⌥cC · Chrome
⌥aA · Claude (C taken, L is focus-right)
⌥sS · Slack
⌥tT · iTerm / Terminal
⌥nN · Notion
⌥eE · Cursor / VS Code
⌥bB · Safari
⌥1–5Free workspaces
⌥⇧wsSend window to that workspace and follow it
⌥⇥Previous workspace (back and forth)
⌥⇧⇥Move workspace to next monitor

AeroSpace Modes

Resize mode · ⌥r

h / lNarrower / wider
j / kTaller / shorter
- / ^Smart shrink / grow
bBalance sizes and exit
↩ / escExit

Service mode · ⌥⇧;

escReload config and exit
rReset layout (flatten tree)
fFloat ↔ tile
bBalance sizes
⌫Close all windows except the focused one
⌥⇧hjklJoin with neighbour (nest windows)

When things go wrong

Shortcuts type letters → quit AeroSpace from the menu bar and reopen it (reload isn't enough).
Window on the wrong workspace → aerospace run-callback --for-every-window on-window-detected

tmux Panes

Press prefix ⌃Space, release, then the key.

v or |Split side by side
s or -Split stacked
hjklSelect pane
HJKLResize pane (hold to repeat)
zZoom / unzoom pane
xKill pane (no confirmation)
qShow pane numbers
{ / }Swap pane with previous / next
!Break pane out into its own window

No prefix needed

⌃hjklMove between panes and nvim splits
⌃Space ⌃lClear the shell screen (plain ⌃l moves right)
